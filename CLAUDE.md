# Merka POS (panel) y proyectos de Autix

Antes de crear o cambiar cualquier cosa que un cliente vaya a leer, comparar o pagar (textos, títulos, botones, precios, planes, páginas, mensajes, correos, SEO, demos, lanzamientos, funciones nuevas), usar la skill `marketing-autix` y leer `.agents/product-marketing.md`. Registrar lo aprendido en la sección Aprendizajes de ese archivo al terminar.

Skills del proyecto (en `.claude/skills/`, copia de `skills/`):
- `marketing-autix`: método general, reglas de la casa y router.
- `copy-web-que-vende`: redacción y auditoría de páginas web.
- `vender-merka-pos`: ventas, demo y objeciones.

Reglas de trabajo:
- Desarrollar en la rama `claude/determined-maxwell-pntedh`. No crear PR salvo que se pida.
- El deploy se hace desde esa rama en EasyPanel.
- Español de Chile, sin emojis. Precios en pesos chilenos, una sola fuente de verdad (la web publicada).
- No inventar testimonios, cifras ni clientes. No usar "partner" ni "autorizado" de Tuu, Haulmer o el SII sin confirmación escrita.
- Las llaves de API no se piden por chat; solo por el panel.
